# Morning Brief — 프로젝트 개요

서비스명: **Morning Brief** — 공개 API 데이터를 모아 매일 아침 요약을 만들어 주는 데일리 브리핑 대시보드.
포트폴리오 프로젝트이며, Next.js 풀스택 앱 하나가 대시보드 UI와 cron 엔드포인트를 모두 담당한다.

## 목적

"아침에 확인하는 정보(날씨·환율·개발 소식·오늘의 한마디)를 한 번에 받아본다"는 개인 자동화를 실제로 동작하는
서비스로 구현한다. 포트폴리오 목적상 다음 역량을 보여주는 데 집중한다.

- 외부 API 연동과 데이터 정규화 (위젯 플러그인 구조)
- 부분 실패에 강한 비동기 처리 (`Promise.allSettled`, 위젯 단위 오류 상태)
- 스케줄링 자동화 (GitHub Actions cron → 보호된 API 엔드포인트) 와 알림 (Telegram Bot)
- 반응형·다크 모드·로딩 스켈레톤을 갖춘 대시보드 UI

## 핵심 흐름

1. 매일 아침 07:00 KST, GitHub Actions cron이 `/api/cron/brief`를 시크릿 토큰과 함께 호출한다.
2. 서버가 등록된 위젯의 외부 API를 병렬 호출하고 결과를 정규화한다.
3. 오늘의 브리핑 스냅샷을 저장한다.
4. 요약을 Telegram으로 전송한다.
5. 사용자는 대시보드에서 오늘의 브리핑과 지난 이력을 본다.

## 범위

- **포함**: 위젯(날씨, 환율, 개발 뉴스, 오늘의 한마디), 브리핑 생성 API, 스냅샷 저장·이력 조회,
  Telegram 전송, 대시보드 UI, 공개 읽기 전용 데모.
- **후순위(MVP 이후)**: LLM 요약(Claude API), 위젯 설정 UI, 이력 차트, 이메일 알림, GitHub 활동 위젯.
- **제외**: 다중 사용자 인증, 로그인이 필요한 사이트 크롤링(Playwright), 유료 API.

## 미결정 사항

- 환율 API: 키 없이 쓰는 무료 API 우선, 한국수출입은행 API는 대안
- LLM 요약 포함 여부 (MVP 이후 결정)
- 저장소: Supabase(Postgres) 또는 Vercel KV 중 택일 — `10_data_model` 작성 시 확정
