# Morning Brief — 코딩 규칙

- Next.js App Router, TypeScript, Tailwind, shadcn/ui 패턴을 따른다. 요청 없이 새 상태관리 라이브러리·
  CSS 프레임워크를 도입하지 않는다.
- `src/components/ui/*`(shadcn 생성 파일)는 직접 수정하지 않는다 — 재생성하거나 감싸는 컴포넌트를 만든다.
- **외부 API 응답은 zod로 검증한 뒤에만 사용한다.** 응답 형태가 바뀌어도 해당 위젯만 오류 상태가 되어야 한다.
- **위젯 호출은 `Promise.allSettled`로 묶는다.** 위젯 하나의 실패가 브리핑 전체를 실패시키면 안 된다.
  실패한 위젯은 오류 상태로 기록하고 나머지를 계속 처리한다.
- 모든 외부 호출에 타임아웃을 둔다 (서버리스 함수 실행 시간 제한 때문).
- 시크릿(Telegram 토큰, cron 토큰, API 키)은 서버 환경변수로만 읽고, 클라이언트 코드·`NEXT_PUBLIC_*`에
  두지 않는다. 커밋 대상은 `.env.example`만이다.
- `/api/cron/*`은 시크릿 토큰을 검증하고, 토큰이 없거나 틀리면 `401`을 반환한다. 토큰 비교는 상수 시간 비교를 쓴다.
- 접근성 기본(레이블, 포커스, 대비)을 지키고, 다크 모드에서도 가독성을 확인한다.
- 외부 문자열(뉴스 제목 등)은 JSX 텍스트로만 표시한다. `dangerouslySetInnerHTML`을 쓰지 않는다.
- 한글 문자열에 조사를 동적으로 붙일 땐 하드코딩하지 말고 헬퍼를 사용한다.
